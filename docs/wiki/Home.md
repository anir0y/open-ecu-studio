# Open ECU Studio classroom guide

Open ECU Studio lets students drive a simulated vehicle and follow a control change into its CAN packets. The same classroom also runs a compiled STM32 reference ECU so students can capture and compare a repeatable wheel-slip event.

1. Set up the browser app, build the Apple Silicon desktop app, or start a virtual network inside a Linux VM. [Installation](https://github.com/anir0y/open-ecu-studio/wiki/Installation)
2. Run your first driving lesson, change lights and doors, inspect packet bytes, and download the measurements from a frozen ESC event. [Usage](https://github.com/anir0y/open-ecu-studio/wiki/Usage)

The source repository includes both guides for offline use. [Open ECU Studio on GitHub](https://github.com/anir0y/open-ecu-studio)
